# 退職後のお金シミュレーター v0.5

退職後のお金の流れを概算で整理するための参考用シミュレーターです。

## 公開版について

- GitHub Pages公開用の `index.html` です。
- スマホ表示に対応しています。
- 入力と結果確認はスマホでもできます。
- 詳細表、バックアップ保存、データ読込、CSV出力、印刷はPC利用を推奨します。

このツールは、個別の年金額、税額、健康保険料、介護保険料、給付金などを確定・保証するものではありません。
計算結果に基づく年金受給タイミング、投資、住み替え、保険見直し、その他の財務判断について、作成者は責任を負いません。

正確な金額や個別判断は、年金事務所、市区町村、税務署、健康保険組合、ハローワーク、社会保険労務士、税理士、ファイナンシャルプランナー等に確認してください。

## データの扱い

入力データは、利用者の端末・ブラウザ内で扱う想定です。作成者のサーバーに保存・送信する設計ではありません。
ただし、表示のために外部CDNからライブラリやフォントを読み込む場合があります。
